# 讨论算法局限性以及失败案例

## 1. 算法局限性

| 局限 | 本轮表现 |
| --- | --- |
| 低频商品较难命中 | GCE-GNN 对目标商品频次排名前 100 的 Recall@10 为 57.86%，对排名 5,000 名以后为 23.38% |
| 更长历史不一定更准确 | GCE-GNN 在历史长度 15–19 次组的 Recall@10 为 29.81%，低于其余长度组 |
| 计算成本较高 | 本轮 GCE-GNN 的训练及验证耗时、批量前向均摊耗时均高于两个对照 |

### 2.1 主模型失败：会话 11348

```text
历史：36687 → 49111 → 1231 → 72246 → 38280
真实下一点击：36687

SR-GNN：第 1 位
GC-SAN：未进入 Top-10
GCE-GNN：未进入 Top-10
```

实际观察：真实目标是历史中最早浏览过的商品，属于回访；SR-GNN 将它排在首位，GCE-GNN 没有进入前 10 位。

这个案例说明，总体指标最高的模型仍可能在某条会话上输给对照模型，结构更复杂也不能保证每次预测更准确。

可进一步检查局部表示、全局邻居和各位置的汇总权重，判断哪一部分影响了该目标的排序。目前没有导出这些内部量，不能直接认定是全局邻居干扰或某一位置权重不足造成失败。

### 2.2 三模型均失败：会话 4829

```text
历史：24817 → 11092 → 10234 → 1961
      → 12922 → 158050 → 46820 → 24200
真实下一点击：57585

三个模型都没有将 57585 排进 Top-10。
```

实际观察：历史有 8 次点击，没有重复商品；真实目标此前未在这条历史中出现。目标商品在训练样本目标频次排名中为第 11,822，属于第五部分的“5,000 名以后”组。

这个案例说明，现有历史和所学商品关系仍可能无法让真实下一点击进入推荐列表。它与低频目标组整体命中率较低的现象相对应，但单个案例不能证明失败完全由目标频次造成。

由于没有商品名称、类别和浏览页面内容，也不能据此判断用户是否跨类别浏览，或给出具体商品层面的业务原因。

### 2.3 对照案例：会话 4998

```text
历史：5152 → 34614 → 13326 → 5152
真实下一点击：34614

SR-GNN、GC-SAN：未进入 Top-10
GCE-GNN：第 1 位
```

这一条同样是对历史商品的回访，但 GCE-GNN 命中，两个对照未命中。结合会话 11348，可以说明三模型对不同历史的排序存在差异，而不是某个模型对全部回访行为都更好。

## 3. 改进方向

| 方向 | 思路 |
| --- | --- |
| 补充商品内容 | 在有真实类别、文本等信息的数据上增强商品表示，尝试改善低频商品推荐 |
| 优化历史信息利用 | 调整位置加权或局部与全局融合方式，尝试减少长历史中无关信息的影响 |
| 控制计算开销 | 调整全局邻居数量，在推荐效果与计算时间之间选择合适配置 |

以上为后续改进思路，本轮尚未执行。
