# 算法设计思想与伪代码描述

本节按照项目当前使用的 RecBole-GNN 实现说明算法，以 GCE-GNN 为主线，以 SR-GNN、GC-SAN 为对照。三种模型分别接收同一任务的历史输入、输出下一点击商品得分，通过统一的实验协议比较。

## 1. 总体设计思想

历史点击既包含当前会话内的商品转移，也可能与其他训练会话中的商品关系有关。三种模型围绕这些信息采用不同的编码方式：

| 模型 | 核心思想 | 会话表示的形成方式 |
|---|---|---|
| SR-GNN | 在当前会话图中进行门控消息传播 | 将最后点击的节点表示与会话内加权汇总表示拼接、变换 |
| GC-SAN | 在图传播得到的序列表示上加入自注意力 | 将自注意力输出的最后位置表示与图传播的最后位置表示加权相加 |
| GCE-GNN | 同时编码当前会话关系和训练集跨会话关系 | 将局部、全局表示相加，再结合位置和会话上下文进行加权汇总 |

共同的输出步骤为：

```text
历史点击序列
    → 商品嵌入与会话图
    → 模型编码得到会话向量 s
    → s 与全部候选商品嵌入计算内积
    → 屏蔽填充商品，取 Top-10
```

这里比较的是三种完整架构。跨会话关系分支的独立作用，需要在同一主模型内进行对应消融后再判断。

## 2. GCE-GNN 的输入、参数与中间表示

### 2.1 输入与输出

| 项目 | 内容 |
|---|---|
| 输入历史 | 按点击时间排列的商品 ID 序列 X |
| 训练监督 | 当前样本的真实下一点击商品 y |
| 训练集全局关系 | 由训练样本构建的商品邻接表及关联计数 |
| 中间表示 | 商品嵌入、局部节点表示、全局商品表示、位置表示、会话向量 |
| 输出 | 全候选商品得分，以及最终 Top-10 推荐列表 |

真实标签 y 在训练时用于全局图统计和损失计算。验证、测试样本的标签不加入全局图统计，也不作为当前预测的历史输入。

### 2.2 关键符号

| 符号 | 含义 |
|---|---|
| E、e_v | 商品嵌入表、商品 v 的嵌入向量 |
| alias | 每个点击位置到当前会话图节点的映射 |
| a_r | 局部关系类型 r 的可学习向量 |
| l_v | 商品 v 的局部图聚合表示 |
| g_v | 商品 v 的全局邻居聚合表示 |
| c | 当前历史中商品嵌入的均值，用于引导全局邻居聚合 |
| u_t | 第 t 个序列位置融合后的局部与全局表示 |
| p_t | 第 t 个序列位置的位置嵌入 |
| β_t | 会话汇总时第 t 个位置的权重 |
| s | 最终会话向量 |

向量维度为 64。下文的 `⊙` 表示逐元素相乘，`concat` 表示拼接，`sum` 表示求和，`mean` 表示均值。公式采用普通文本形式。

## 3. GCE-GNN 的核心机制

### 3.1 整理历史并构建局部会话图

**输入：**按时间正序排列的历史点击。

当前实现首先反转历史，使最近一次点击位于序列最前端。随后将相同商品映射到同一个图节点，并保留每个点击位置对应的节点索引 alias。重复点击在序列中保留，在图中共享节点。

局部图根据相邻点击加入方向关系，并加入自环。类型编号相对于反转后的序列定义：

| 类型编号 | 关系含义 |
|---|---|
| 0 | 显式加入的自环 |
| 1 | 沿反转后序列方向的相邻连接，且原相邻连接集合中不存在反向边 |
| 2 | 为上述单向连接补充的反向连接 |
| 3 | 原相邻连接集合中同时存在两个方向的关系 |

代码按“起点、终点、关系类型”三元组去重。因此，同一对节点若对应不同关系类型，可以保留不同的边；连续重复点击还可能同时产生类型 3 的连接与类型 0 的自环。

**输出：**节点商品 ID、边、关系类型、位置到节点的映射，以及有效位置掩码。

### 3.2 构建训练集全局商品图

**输入：**训练集中的“历史—目标”样本。

对每条训练样本，取反转后历史的前 4 个有效位置，也就是距离该训练目标最近的至多 4 次历史点击。将训练目标商品与这些历史商品建立双向连接，并累计关联次数。

对每个商品，将邻居按关联计数从高到低排序，保留前 12 个。邻居不足 12 个时，用索引 0 和权重 0 补齐。该过程在模型初始化阶段进行，训练过程中复用这份全局邻接信息。

这里的“12 个邻居”是按计数截取的固定邻居表。重复点击和不同训练前缀都可能累加关联计数，权重表达的是代码中的累计次数。

**输出：**全局邻接表 `global_adj` 与对应计数 `global_weight`。

### 3.3 局部关系注意力聚合

**输入：**当前会话图、节点嵌入和关系类型。

对一条从邻居 j 指向节点 i 的边，模型结合两端嵌入与关系类型向量计算关联得分：

```text
score_(j→i) = LeakyReLU( sum(e_j ⊙ e_i ⊙ a_r) )
α_(j→i) = softmax(所有指向节点 i 的边的 score)
l_i = Σ[j→i] α_(j→i) × e_j
```

softmax 在同一接收节点的入边之间归一化。模型可以根据当前节点、邻居商品及连接类型，为不同消息分配不同权重。

**输出：**每个当前会话节点的局部表示 l_i。当前实现执行一次这样的局部聚合。

### 3.4 会话上下文引导的全局聚合

**输入：**当前历史的原始商品嵌入、商品的全局邻居及其关联计数。

先在当前历史的有效位置上计算商品嵌入均值 c。重复点击对应的嵌入会按出现次数进入均值，因此 c 是序列位置的均值，不是不同商品集合的均值。

对于当前商品 v 的各个邻居 k，将会话上下文与邻居嵌入逐元素相乘，并拼接关联计数 w_vk：

```text
c = mean(当前历史中各有效位置的商品嵌入)
a_vk = LeakyReLU( concat(c ⊙ e_k, w_vk) W_1 ) W_2
α_vk = softmax_k(a_vk)
n_v = Σ[k] α_vk × e_k
g_v = ReLU( concat(e_v, n_v) W_3 )
```

同一商品的邻居关联计数是固定的，聚合权重还会随当前会话上下文变化。全局分支因此能够根据当前历史，从训练集商品关系中提取补充表示。

当前配置使用一跳邻居。源码将邻居表补足为 12 个槽位，聚合时没有对补位邻居另加 softmax 掩码；上述公式中的邻居槽位包括补位项。真实的嵌入与权重处理应以这一实现为准。

**输出：**各历史位置对应商品的全局表示 g_v。

### 3.5 局部与全局表示融合

**输入：**局部节点表示、全局表示和 alias 映射。

局部表示先根据 alias 还原到各点击位置，再与对应全局表示相加：

```text
u_t = Dropout(l_alias[t], p=0.0)
      + Dropout(g_t, p=0.5)
```

这里是直接相加。当前融合步骤没有可学习的“局部与全局混合比例”。训练时对全局表示使用 0.5 的 dropout，验证和推理时关闭 dropout。

接下来，将位置嵌入 p_t 与融合表示 u_t 拼接，结合融合表示的会话均值计算位置权重：

```text
c_fused = mean(各有效位置的 u_t)
q_t = tanh( W_pos concat(p_t, u_t) )
b_t = sigmoid( Linear_1(q_t) + Linear_2(c_fused) )
β_t = Linear_3(b_t)
s = Σ[有效位置 t] β_t × u_t
```

位置以反转后序列为准，最前面的有效位置对应最近点击。位置权重 β_t 在当前源码中没有经过 softmax，不能解释成各位置和为 1 的概率分布。最终求和时屏蔽填充位置。

**输出：**64 维会话向量 s。

### 3.6 全候选打分、监督学习与推荐

将会话向量与整个商品嵌入表相乘，得到全部商品的分数：

```text
z_j = sᵀ e_j
```

训练时，用真实下一点击 y 计算全类别交叉熵，并通过反向传播更新嵌入与网络参数。当前训练 logits 包括嵌入表中的索引 0；推荐输出与评价时将索引 0 的得分屏蔽。

推理时，取 32,968 个真实候选商品中得分最高的 10 个，映射回原始商品 ID。历史中已经出现过的商品仍可被推荐。

## 4. GCE-GNN 伪代码

以下伪代码以按时间正序排列的历史 X 为外部输入。实际程序由数据层或推理适配层完成反转与构图，网络接收已经处理好的图数据。伪代码展示端到端算法步骤，适用于当前一跳全局邻居配置。

### 4.1 训练集全局图构建

```text
算法：BuildGlobalGraph
输入：训练样本 D_train，每条样本为历史 X 和目标 y
输出：全局邻接表 A，以及关联计数 W

1. 初始化所有商品的邻居计数字典 Count
2. 对 D_train 中每条 (X, y)：
       X_rev ← 反转 X
       对 X_rev 前 4 个有效位置上的商品 v：
           Count[y, v] ← Count[y, v] + 1
           Count[v, y] ← Count[v, y] + 1
3. 对每个商品 v：
       将 Count[v] 中的邻居按计数降序排列
       A[v] ← 前 12 个邻居
       W[v] ← 对应的关联计数
       不足 12 个时，用索引 0 和计数 0 补齐
4. 返回 A, W
```

### 4.2 单条历史的前向计算

```text
算法：GCEForward
输入：历史 X，全局邻接表 A、计数 W，模型参数 θ，模式 mode
输出：会话向量 s，以及全商品得分 z

1. X_rev ← 反转 X
2. 将 X_rev 的商品映射为图节点，保留位置到节点的 alias
3. 根据相邻位置、反向连接、双向关系与自环构建带类型局部图
4. 按“起点、终点、类型”去重；生成有效位置掩码 mask
5. H ← 从商品嵌入表查找各节点的原始嵌入

6. 对每个接收节点 i：
       根据两端嵌入及关系类型，计算各入边的注意力得分
       对入边得分进行 softmax
       L[i] ← 按注意力权重汇总入边发送节点的原始嵌入

7. c ← X_rev 各有效位置的原始商品嵌入均值
8. 对 X_rev 中各有效位置对应的商品 v：
       读取 A[v] 的 12 个邻居槽位、W[v] 与邻居嵌入
       将 c 与邻居嵌入逐元素相乘，再拼接关联计数
       计算注意力分数，对全部 12 个槽位进行 softmax
       n_v ← 加权汇总邻居嵌入
       G[v] ← ReLU(对 concat(e_v, n_v) 进行线性变换)

9. L_seq ← 根据 alias 将 L 还原到点击序列各位置
10. U ← Dropout(L_seq, 0.0) + Dropout(G_seq, 0.5)
        mode 为验证或推理时，关闭 dropout
11. c_fused ← U 在有效位置上的均值
12. 对每个有效位置 t：
        拼接位置嵌入 p_t 与 U[t]，经过线性变换和 tanh
        结合 c_fused，经过门控计算得到位置权重 β_t
        β_t 不进行 softmax
13. s ← Σ[有效位置 t] β_t × U[t]
14. z ← s 与整个商品嵌入表的转置相乘
15. 返回 s, z
```

批处理实现会将序列和邻居张量补齐到配置长度，再使用有效位置掩码完成会话汇总。G_seq 表示全局结果还原到序列位置后的张量。

### 4.3 训练与选模

```text
算法：TrainGCEGNN
输入：D_train、D_valid，正式配置
输出：验证集 MRR@10 最优的 checkpoint

1. 设置随机种子 42，准备数据划分
2. A, W ← BuildGlobalGraph(D_train)
3. 初始化商品嵌入、位置嵌入及各网络参数，建立 Adam 优化器
4. best_mrr ← 初始最差值
5. 按最多 20 轮进行训练：
       将模型切换为训练模式
       对每个大小不超过 128 的训练批次 (X, y)：
           清空梯度
           s, z ← 批量执行 GCEForward(X, A, W, θ, 训练)
           loss ← 全类别交叉熵(z, y)
           反向传播，使用 Adam 更新 θ
       将模型切换为验证模式
       屏蔽填充商品，使用验证集计算 MRR@10
       若验证指标改善，保存参数及 A、W
       若触发框架 stopping_step=5 的早停条件，结束训练
6. 返回验证指标最优的 checkpoint
```

全局邻接表和计数作为额外状态随 checkpoint 保存。邻接关系在该次训练中固定，商品嵌入和聚合网络参数通过训练更新。

### 4.4 加载模型并推荐

```text
算法：RecommendTop10
输入：商品原始 ID 序列 X，以及已训练的 checkpoint
输出：10 个原始商品 ID、排名及模型得分

1. 加载模型参数，以及保存的全局邻接表 A 与计数 W
2. 检查输入非空，且商品 ID 属于当前词表
3. 历史超过 20 次点击时，仅保留最后 20 次
4. 将原始 ID 转为内部索引
5. 切换为推理模式，关闭梯度计算与 dropout
6. s, z ← GCEForward(X, A, W, θ, 推理)
7. z[0] ← 负无穷，排除填充商品
8. 取分数最高的 10 个不同商品
9. 将内部索引转回原始 ID，返回排名与分数
```

实际交互实验台会缓存已加载的模型。模型实例初始化时会准备数据与图结构，然后加载 checkpoint 中的参数及全局图状态；缓存后的每次推荐复用这些状态。

## 5. 两种对照算法的设计思想与伪代码

### 5.1 SR-GNN：门控图传播与会话汇总

SR-GNN 将时间正序历史转换为局部有向图，对重复的有向边去重。每个节点分别聚合入向和出向邻居信息，再通过门控单元更新节点状态。当前配置执行一步图传播。

随后，根据 alias 还原各序列位置的节点状态。最后一次点击对应的表示 h_last 表达最近行为；模型结合 h_last 与各位置状态计算汇总权重 α_t，形成会话内汇总向量 a：

```text
α_t = Linear_3( sigmoid(Linear_1(h_last) + Linear_2(h_t)) )
a = Σ[有效位置 t] α_t × h_t
s = Linear_transform( concat(a, h_last) )
```

当前源码中的 α_t 同样没有经过 softmax。这里的会话内汇总只使用当前历史，它与 GCE-GNN 的跨会话全局图表示是不同概念。

```text
算法：SRGNNForward
输入：时间正序历史 X
输出：全商品得分 z

1. 按商品构建会话节点、相邻点击有向边与 alias，重复边去重
2. 查找节点嵌入 H
3. 分别线性变换并均值聚合入向、出向邻居消息
4. 拼接两类消息，通过门控单元更新 H
5. 根据 alias 还原序列位置表示，提取 h_last
6. 计算各位置权重 α_t，加权求和得到 a
7. s ← 对 concat(a, h_last) 进行线性变换
8. z ← s 与整个商品嵌入表的转置相乘
9. 返回 z
```

### 5.2 GC-SAN：图上下文与自注意力融合

GC-SAN 先进行与 SR-GNN 同类的门控图传播，再将节点状态还原为序列表示。自注意力模块在这些表示上建模会话内不同位置的关系。当前配置为一层、单头，使用填充掩码和从左向右的注意力掩码。

取图传播后最后一个位置的表示 h_last，以及自注意力最后一个位置的表示 a_last，按配置融合：

```text
s = 0.6 × a_last + 0.4 × h_last
```

0.6 是当前配置固定的混合权重。输出再与商品嵌入表计算内积。训练损失在交叉熵之外，还包括商品嵌入正则项。

```text
算法：GCSANForward
输入：时间正序历史 X
输出：全商品得分 z

1. 构建局部会话图与 alias，查找节点嵌入
2. 通过一步门控图传播更新节点表示
3. 根据 alias 还原为序列表示 H_seq
4. h_last ← H_seq 的最后一个有效位置
5. 构建填充掩码及从左向右的注意力掩码
6. A_seq ← 自注意力编码器(H_seq, 掩码)
7. a_last ← A_seq 的最后一个有效位置
8. s ← 0.6 × a_last + 0.4 × h_last
9. z ← s 与整个商品嵌入表的转置相乘
10. 返回 z
```

## 6. 当前实现的关键配置

| 配置项 | 当前值 | 对算法过程的影响 |
|---|---|---|
| 商品与会话表示维度 | 64 | 决定表示与主要变换的维度 |
| 最大输入历史长度 | 20 | 限制每条样本使用的历史长度 |
| GCE-GNN 全局构图窗口 | 最近至多 4 次历史点击 | 决定训练目标与哪些历史位置累计关联 |
| GCE-GNN 全局邻居数 | 12 | 每个商品保留固定长度邻居表 |
| GCE-GNN 全局跳数 | 1 | 当前仅聚合一跳邻居 |
| GCE-GNN 局部 dropout | 0.0 | 当前不随机丢弃局部融合分支的分量 |
| GCE-GNN 全局 dropout | 0.5 | 训练时作用于全局融合分支，推理时关闭 |
| GCE-GNN 聚合器内部 dropout | 0.0 | 当前全局聚合器内部不启用 dropout |
| SR-GNN / GC-SAN 图传播步数 | 1 | 当前执行一步门控更新 |
| GC-SAN 自注意力层数、头数 | 1 层、1 头 | 决定自注意力编码结构 |
| GC-SAN 前馈层内部维度 | 256 | 用于自注意力编码器中的前馈变换 |
| GC-SAN 混合权重 | 0.6 | 自注意力最后位置表示的融合系数 |
| GC-SAN 嵌入正则系数 | 5 × 10⁻⁵ | 加入其训练损失 |
| 训练损失 | 全类别交叉熵 | 通过下一点击监督学习排序得分 |
| 优化器与学习率 | Adam，0.001 | 更新可学习参数 |
| 批量大小 | 128 | 每个训练批次的样本上限 |
