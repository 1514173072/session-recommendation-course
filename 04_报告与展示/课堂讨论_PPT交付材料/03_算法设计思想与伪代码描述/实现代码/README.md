## 1. 文件及用途

| 文件 | 主要内容 | 汇报用途 |
| --- | --- | --- |
| [gcegnn.py](gcegnn.py) | GCE-GNN 的局部关系聚合、全局邻居聚合、表示融合、会话汇总、损失和商品打分 | 主模型设计思想与前向计算伪代码 |
| [srgnn.py](srgnn.py) | SR-GNN 的图传播调用、会话表示、损失和打分 | 对照模型：局部会话图与门控传播 |
| [gcsan.py](gcsan.py) | GC-SAN 的图传播、自注意力、表示融合、损失和打分 | 对照模型：图上下文与自注意力结合 |
| [layers.py](layers.py) | 包含 SRGNNConv、SRGNNCell 等图网络组件 | 查阅前两种对照模型使用的入向、出向消息聚合及门控更新 |
| [run_formal.py](run_formal.py) | 正式实验入口：数据准备、模型初始化、训练、最佳权重评估及结果保存 | 训练与选模伪代码 |
| [formal.yaml](formal.yaml) | 三模型共用的训练、数据划分和评价配置 | 解释共同训练协议与选模设置 |
| [GCEGNN.yaml](GCEGNN.yaml) | GCE-GNN 专属配置，包括邻居数、跳数及 dropout | 对照主模型结构中的具体参数 |
| [SRGNN.yaml](SRGNN.yaml) | SR-GNN 专属配置，包括嵌入维度和图传播步数 | 说明对照模型设置 |
| [GCSAN.yaml](GCSAN.yaml) | GC-SAN 专属配置，包括注意力层数、头数和融合权重 | 说明自注意力与图表示的融合设置 |

记录中的相对路径以“完整项目”目录为基准；上一级材料的 Markdown 链接仍相对于各自所在文件夹。

## 2. 建议阅读顺序

1. 先阅读上一级的 [算法设计思想与伪代码描述.md](../算法设计思想与伪代码描述.md)，了解整体计算流程。
2. 阅读 `gcegnn.py`，重点按“构图 → 两条聚合分支 → 融合 → 会话汇总 → 商品打分”理解主模型。
3. 阅读 `srgnn.py` 和 `gcsan.py`，比较三种模型形成会话向量的方式；门控传播细节查阅 `layers.py`。
4. 阅读配置文件，确认维度、邻居数和训练设置。
5. 阅读 `run_formal.py` 的 `main()`，对应训练、验证选模与最终测试流程。

## 3. GCE-GNN 核心代码与算法步骤

| 算法步骤 | 对应类或函数 | 输入 → 处理 → 输出 |
| --- | --- | --- |
| 构建训练集全局商品图 | `GCEGNN.construct_global_graph()` | 训练历史与目标 → 累计关联次数、按计数保留邻居 → 全局邻接表与关联计数 |
| 局部关系聚合 | `LocalAggregator.message()` | 会话图节点、边类型 → 对接收节点的入边计算注意力并聚合 → 局部节点表示 |
| 全局邻居聚合 | `GlobalAggregator.forward()` | 商品、邻居、关联计数与会话上下文 → 上下文引导的邻居聚合 → 全局表示 |
| 双分支融合 | `GCEGNN.forward()` | 局部节点表示映射回点击位置，与全局表示相加 → 融合序列表示 |
| 会话汇总 | `GCEGNN.fusion()` | 融合表示、位置嵌入和掩码 → 计算位置权重并求和 → 会话向量 |
| 监督训练 | `GCEGNN.calculate_loss()` | 会话向量与商品嵌入 → 全商品得分及交叉熵 → 训练损失 |
| 全候选打分 | `GCEGNN.full_sort_predict()` | 会话向量与商品嵌入表 → 内积 → 全商品得分矩阵 |

模型的 `full_sort_predict()` 返回全部商品的得分。屏蔽填充索引、排序和取 Top-10 由评价或预测导出环节完成，不能将该函数本身理解为直接返回 10 个商品 ID。
