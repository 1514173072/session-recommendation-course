## 灰关联是什么意思

这里的灰色关联分析是一种多指标推荐打分方法。输入当前浏览会话，为每个候选商品计算四项证据：最后点击的转移关联、与浏览历史的共现关联、当前会话中的历史支持、商品热度。

四项证据归一化后，与理想参考值比较，计算灰色关联系数，再按各 25% 的固定权重汇总。得分最高的十个商品作为推荐结果。

**流程：浏览历史 → 四项商品特征 → 灰色关联系数 → 等权打分 → Top-10。**

## 普通 MLP 是什么意思

MLP 是多层感知机，一种小型前馈神经网络。本次实现用六项会话状态作为输入，包括会话长度、不同商品比例、最后商品是否重复、最高商品重复比例、最后商品热度及其转移熵（后续点击分布的分散程度）。经过 16 个隐藏单元，输出十个评分参数：四个特征权重和六个两两交互系数，共 282 个可训练参数。

它沿用上述四类商品证据，但通过真实下一点击训练，学习如何按会话状态调整权重，以及两类证据共同出现时如何评分。

**流程：会话状态 → 本地 MLP → 权重与交互系数 → 商品打分 → Top-10。**

## 教师指导 MLP 是什么意思

教师是提供训练指导的强模型，学生是实际运行推荐的小型 MLP。本次由当前对话助手读取训练侧统计，编写十二类会话情境下的权重及关联组合指导，再确定性生成 2,000 条训练指导记录。

学生同时学习真实下一点击和教师提供的评分参数。它与普通 MLP 的网络结构相同，区别是训练时增加了教师指导。训练完成后，推荐全过程在本地运行。

**离线：教师分析训练证据 → 生成指导 → 结合真实点击训练 MLP。**

**在线：会话输入 → 本地 MLP → 商品打分 → Top-10。**

## 图表和 CSV 怎么看

- `推荐质量与耗时对比.png`：以表格呈现六种方法的推荐质量与平均耗时。Recall@10 越高，真实下一商品进入前十名的比例越高；MRR@10 越高，真实商品整体排得越靠前；平均响应时间越低，推荐计算越快。
- `扩展对比结果.csv`：保留六种方法的完整数值。推荐指标以 0—1 小数保存，时间单位为毫秒，内存 MB 按 1,000,000 字节换算。数值状态包含统计数组和模型参数；进程内存还包含 Python、计算框架等。

当前测试中，普通 MLP 的 Recall@10 为 36.375%，教师指导 MLP 为 36.475%，净多命中 20 个会话；MRR@10 从 0.16768 升至 0.17242。教师指导版平均响应时间为 0.777 毫秒，原始灰关联为 0.641 毫秒，GCE-GNN 为 2.035 毫秒。

数据范围为 20,000 个测试会话、32,968 个候选商品；沿用会话内留后划分。耗时是在同一批 300 条请求上测量三轮的预热后本地计算时间，包含特征或图构建、全商品评分与 Top-10，排除启动和网络。结果来自当前单数据、单种子设置；教师指导记录由十二类原型生成，本次未测量大模型 API 耗时。
