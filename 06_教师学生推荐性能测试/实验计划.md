# 教师关联指导与轻量学生：独立性能测试

本实验仅用于用户的性能探索，不纳入《灰预测与决策方法》课程论文。

## 固定方案

1. 读取实际训练划分，检查三个 GNN 的划分指纹及商品映射。
2. 保留原始四特征和全商品 min-max。上下文固定六项：log 会话长度、不同商品比例、最后商品是否重复、最高商品重复比例、最后商品训练热度、最后商品转移熵。
3. 从 97,273 个训练样本构造正样本和固定负样本；仅训练时允许加入真实正商品。验证/测试始终对全部 32,968 个商品排名。训练特征采用按会话五折交叉拟合的统计量，排除自己所在会话折，避免自身目标进入转移/共现特征；推理仍复用全训练统计。
4. 按长度（1–3、4–7、8+）、最后商品是否重复、最后商品热度分为 12 类。助手先阅读训练侧特征证据，再编写每类四项权重和六项有界交互系数及理由。教师原型冻结后不按测试结果改写。
5. 抽取 2,000 个训练前缀，应用已冻结的情境原型，保存指导标签。该过程是助手原型的确定性展开，不是 2,000 次 LLM 调用。
6. 学生 6→16→10，ReLU 隐藏层，4 项 softmax 权重、6 项 0.5*tanh 交互系数，共 282 参数。候选得分为四特征加权和加六个两两乘积项。
7. 两个学生均训练全部原有训练前缀，seed=42，Adam、lr=0.003、batch=512、30 epochs。监督为 32 候选中的真实点击交叉熵，温度 0.1。有教师学生另加指导系数 MSE（系数 1）。每 5 轮在固定抽取的 2,000 验证样本上按 MRR@10 选择轮次，随后冻结。
8. 比较原灰关联、β=7 灰关联、三个 GNN、无教师学生、有教师学生，以及教师原型规则直接执行。复核全测试预测，统一测量 300 请求×3 轮的完整本地推荐时间。
9. 分开记录 282 参数的 FP32 字节、行为统计状态字节、加载后进程内存和计时范围。教师规则执行不代表大模型在线推理。

## 验收

- 训练、验证、测试指纹一致，教师证据不使用验证/测试目标。
- 教师原型、2,000 指导记录、模型权重和训练记录落盘。
- 两学生可以独立重载；全测试预测合法且指标可独立复算。
- 同一批请求上完成八种实现的计时，并检查重载结果与保存预测一致。
- 比较报告提供真实推荐指标、耗时、状态大小及失败案例；不填写未测的大模型 API 耗时。
