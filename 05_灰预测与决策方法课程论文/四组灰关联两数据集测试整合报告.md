# 四组灰关联单因素试验：两数据集结果与分析

本文件整合四组灰色关联改动的研究问题、实际公式、参数选择、完整测试结果、分组分析、响应耗时与结论，可独立阅读。实验记录日期：2026-11-13。

当前论文暂定题目为《面向电商会话推荐的灰色关联模型改进与比较研究》，按五章结构组织。原版与四组的数学性质及A/B部分排序关系，见[统一数学推导](方法与响应曲线推导.md)。

**主要发现：A分辨系数调优、B差异压缩均改善两个数据集的总体推荐质量；C转移指标权重调优在两数据集选择了相反方向；D转移—共现交互惩罚未获得有利改动，均选择恢复原版。** Diginetica中B的三项质量指标最高；Amazon-M2中GC-SAN的Recall与NDCG最高，C的MRR最高。

## 1. 研究任务与比较范围

输入当前会话的商品浏览序列，输出下一次点击商品的Top-10推荐列表。每条测试会话只有一个真实目标。

输入历史序列 → 构造候选商品指标 → 计算灰色关联系数 → 聚合评分 → 按数据集规则过滤 → 输出Top-10。

比较方法共8种：原版灰色关联、四组独立改动A/B/C/D、SR-GNN、GC-SAN、GCE-GNN。四组分别只改变一个环节，不叠加。三个GNN读取原有检查点重新完成测试推理与计时，本轮未重训。Qwen属于另行探索，其历史结果仍在HTML保留，不纳入本轮8方法统一计时表。

| 条件 | Diginetica | Amazon-M2 ES |
|---|---|---|
| 完整验证会话 | 20,000 | 8,886 |
| 完整测试会话 | 20,000 | 8,970 |
| 候选商品目录 | 32,968件 | 42,503件 |
| 灰关联指标 | 转移、共现、重复浏览、热度，共4项 | 转移、共现、文本、品牌、颜色、材质、价格、热度，共8项 |
| 指标构造 | 每个请求按完整目录进行收益型min-max；常量指标置零 | 使用既有0—1行为统计和属性相似度；没有额外套用Dig的逐请求min-max |
| 历史商品过滤 | 允许再次推荐已浏览商品 | 排除当前历史内商品；测试目标不在历史中 |
| GNN输入 | 已有会话图模型 | 已有属性融合模型 |

两数据集的指标、划分和候选规则不同，分别在各自内部比较方法。绝对命中率差异不能直接解释为数据难度差异。

## 2. 原版与四组改动

### 2.1 原版灰色关联

设指标矩阵为 $z_{ki}\in[0,1]$，第 $i$ 列为候选商品，第 $k$ 行为评价指标。参考序列取全1，差异为：

$$d_{ki}=|1-z_{ki}|$$

每次请求在指标与完整候选目录上计算差异极值：

$$d_{\min}=\min_{k,i}d_{ki},\qquad d_{\max}=\max_{k,i}d_{ki}$$

$$\xi_{ki}=\frac{d_{\min}+\rho d_{\max}}{d_{ki}+\rho d_{\max}},\qquad S_i=\frac1F\sum_{k=1}^{F}\xi_{ki}$$

原版取 $\rho=0.5$、等权算术聚合。代码在所有差异均为0时令关联系数全为1。完整候选目录不含填充ID；Amazon历史过滤在评分后执行。

### 2.2 四组单因素设计

| 组别 | 唯一改变的环节 | 实际实现 | 5档候选参数 | 恢复原版参数 |
|---|---|---|---|---|
| A | 分辨系数 | 全部指标统一使用一个 $\rho$ | 0.1、0.25、0.5、0.75、1 | $\rho=0.5$ |
| B | 差异映射 | $d'=d/[1+\beta(1-d)]$；再用变换后差异重算极值及关联系数 | 0、1、2、7、15 | $\beta=0$ |
| C | 转移指标权重 | $w_1=e^\lambda/(e^\lambda+F-1)$，其余各 $w_k=1/(e^\lambda+F-1)$ | −2、−1、0、1、2 | $\lambda=0$ |
| D | 转移—共现一对交互 | $S_i=\mathrm{mean}(\xi_{ki})-(\eta/F)|\xi_{1i}-\xi_{2i}|$ | 0、0.25、0.5、0.75、1 | $\eta=0$ |

四组参数均为数据集级固定值。C不是逐会话自适应赋权；D只研究固定一对指标的非负不一致惩罚。每组保留原版选项，允许得到“没有有利改动”的结果。

四组文献方向及与原文方法的区别，沿用已有[文献依据核对记录](参考文献/四组单因素试验/文献依据核对.md)。这些试验是文献方向下的任务简化，不能统称为复现四篇论文。原PDF留在本地，GitHub提供核对记录与原文链接。

## 3. 选参、评测与核验

每数据集实际执行17种不同配置：1种原版，加上每组4种非原版配置。四组各自5档中的恢复参数共享原版结果。

选参只使用本轮完整验证集，优先最大化MRR@10；依次以Recall、NDCG处理并列，再优先恢复原版及原网格顺序。冻结参数后，在完整测试集评价。

| 指标 | 含义 |
|---|---|
| Recall@10 | 真实下一商品进入前十的会话比例；本任务与Hit@10相同 |
| MRR@10 | 目标位于前十时取倒数排名，未命中取0，再对全部会话求平均 |
| NDCG@10 | 目标位于前十时取 $1/\log_2(r+1)$，未命中取0，再对全部会话求平均 |

两套测试集此前已有查看记录；本轮参数选择未使用测试指标，但整体仍属于既有划分上的扩展性探索。当前没有多划分或多训练种子的稳定性证据，也没有对性能差异作显著性检验。

## 5. A组：分辨系数调优为何有效

**两个数据集均选择将ρ从0.5提高到1，三项总体质量指标均提高。** Diginetica净增加606条命中，Amazon净增加117条。

在差异极值为0和1时，单项响应可化为：

$$\xi_\rho(z)=\frac{\rho}{1-z+\rho}$$

提高ρ使递增曲线的凸性减弱：相对于单项达到理想值的商品，中等强度证据的相对贡献提高。排序变化来自汇总时相对贡献的改变；所有分数一起上升本身不能解释排名改善。

假设4指标商品甲为 $(1,0,0,0)$，商品乙为 $(0.4,0.4,0.4,0.4)$。原版平均分分别约0.500、0.455；ρ=1时两者均约0.625。这个示例仅展示公式偏好，不是实际商品案例。

Diginetica的实测分组支持其收益覆盖两类目标：重复点击Recall从78.99%升至86.47%，新商品目标从8.18%升至9.37%。这里“新商品目标”仅指当前会话未浏览，不等于训练中未出现。

Amazon的训练已见目标Recall从47.33%升至48.68%，训练未见目标从20.0%降至19.5%（40条命中变39条）。其总体收益主要来自已有训练证据覆盖的目标。

可支持的解释是：当前原版评分对中等指标值的响应不足，提高ρ改善了证据聚合。两个数据集收益幅度不同，与其指标构造和候选规则不同相容；现有结果不能把差距唯一归因到某项属性。

## 6. B组：差异压缩为何收益最大，参数为何不同

B保留单项指标内部顺序，改变进入算术聚合前的响应曲率。在差异极值为0和1、ρ=0.5时：

$$\xi_\beta(z)=\frac{1+\beta z}{3+(\beta-2)z}$$

| β | 曲线 | 汇总评分的偏好 |
|---|---|---|
| 0，原版 | 凸 | 更强调接近理想值的强证据 |
| 2 | 线性 | 指标增量对应均匀评分增量 |
| 7 | 凹 | 低到中等水平的提升更有价值，高值段边际收益递减 |

前述假设商品甲、乙在β=7时约为0.500、0.760，体现多项有效支持获得更高相对贡献。相对于原版，这种偏好可以改变商品间的综合排序。

### 6.1 Diginetica：重复目标与新商品目标均增加命中

B选择β=7，Recall提高6.665个百分点，MRR和NDCG也提高。重复目标净增加789条命中，新商品目标净增加544条。

不过，新商品组MRR从0.03644降至0.03475，Recall却从8.18%升至12.02%。因此该组表现为更多目标进入前十，但倒数排名平均收益下降；总体MRR提升主要由重复目标组贡献。不能把总体提升写成每一类请求的每项指标都改善。

### 6.2 Amazon：更强压缩提高Recall，但验证MRR下降

验证集β=2的Recall为49.325%、MRR为0.33909；β=7为50.079%、0.33720；β=15为50.225%、0.33131。按MRR优先的既定目标，选择β=2。

这表明Amazon当前设置更适合温和的线性响应；更强压缩进一步增加前十命中，却损失前部排名质量。此前Amazon固定β=7的历史Recall约50.37%，不能标成此次β=2的结果；新版B的49.509%来自验证选中的不同参数。

训练已见目标Recall从47.33%升至50.24%；训练未见的200条目标命中从40条减为35条。当前收益集中在训练已见目标，不支持冷启动改善。

## 7. C组：权重方向为何在两个数据集相反

C保持单项关联系数不变，只改变转移项相对其余指标的贡献。由于其他指标平分剩余权重，降低转移也同时提高其余各项的相对权重。

| 数据集 | 参数 | 转移权重 | 其他每项权重 |
|---|---:|---:|---:|
| Diginetica原版 | λ=0 | 25% | 25% |
| Diginetica C | λ=−1 | 10.92% | 29.69% |
| Amazon原版 | λ=0 | 12.5% | 12.5% |
| Amazon C | λ=2 | 51.35% | 6.95% |

### 7.1 Diginetica：改善重复目标排名，牺牲新目标覆盖

C的总体Recall从28.875%降至27.560%，MRR却从0.14375升至0.15268，NDCG也从0.17848升至0.18230。

重复目标Recall从78.99%升至79.90%，MRR从0.40362升至0.47170；新商品目标Recall从8.18%降至5.95%，MRR从0.03644降至0.02094。重复组净增加53条命中，新目标组净减少316条，总体净减少263条。

机制上，弱化最后点击转移，同时增强重复、共现、热度的相对贡献，结果与偏向重复目标的取舍一致。该参数被选中，是因为验证集同样按MRR优先：验证MRR从0.14170升至0.14396，尽管Recall下降。它不适合被描述成“所有性能均提升”。

### 7.2 Amazon：提高转移权重，增强接续点击证据

Amazon有8项指标，原等权转移只占12.5%。转移统计直接提供最后商品之后的历史接续点击证据；文本、品牌、颜色等提供商品属性相似性。将转移提高到51.35%后，三项总体质量指标均改善。

训练已见目标Recall从47.33%升至50.05%；训练未见目标从20.0%降至19.5%，MRR也下降。改善仍集中在已见目标，不能概括为所有商品都应增加转移权重。

这组试验支持：固定等权的适用性依赖指标组合与评价目标。不同数据集需要的权重方向可能相反；本轮只测试一个固定权重参数，没有证明该权重跨划分稳定。

## 8. D组：一致性惩罚为何失败

D惩罚转移与共现关联系数的差异。当η=1时，两项合计贡献为：

$$\frac{\xi_1+\xi_2-|\xi_1-\xi_2|}{F}=\frac{2\min(\xi_1,\xi_2)}F$$

这使两者中较弱的信号限制合计贡献。转移强但共现一般，或反之，都可能被额外扣分。两种指标描述不同关系，其不一致本身可能包含有用的互补信息。

完整验证集上，η从0、0.25、0.5提高至1时：Diginetica MRR依次为0.14170、0.13769、0.12939、0.11487；Amazon依次为0.32890、0.32380、0.31452、0.28467。正向惩罚没有获得有利参数。

两个数据集最终均选择η=0，因此测试推荐与原版相同。微小耗时差异属于测量波动。可得结论是当前这对指标、这个方向的一致性惩罚不适用；不能推出所有交互聚合都无效。

## 10. 耗时、复杂度与轻量化

统一协议：CPU 4线程、batch=1，每数据集固定相同300条测试请求；每方法预热30次，再以随机方法顺序执行3轮，共900次测量。质量评价覆盖完整测试集，计时是其中固定样本的重复测量。

计入：内部商品ID历史输入 → 指标或会话图构造 → 全目录评分 → 对应数据集过滤 → Top-10。排除模型加载、静态目录预计算、序列化和写盘。Amazon GNN的属性目录缓存已在最后一次eval后预计算，且计入数值状态；开发阶段未缓存的计时不作正式结果。

设候选数为N，指标数为F。四组对已有指标矩阵的评分均保持O(FN)，Top-10还需目录遍历与选择。完整响应还包括各自指标构造，Amazon的文本和属性计算与Dig不同；不能仅以O(FN)代表全部实现成本。

| 改动 | 运算影响 | 实测解释 |
|---|---|---|
| A | 替换分辨系数常数，数组运算结构基本不变 | 与原版处于同一耗时量级，小幅差异不证明算法加速 |
| B | 新增差异映射的逐元素运算与中间数组 | Dig 0.763→0.803 ms；Amazon 3.725→5.149 ms，常数开销增加 |
| C | 等权改为固定加权，保持同阶线性聚合 | Dig 0.735 ms；Amazon 4.132 ms，精确耗时受数组路径与测量波动影响 |
| D | 非零时增加一对绝对差与惩罚；选中零时走原版评分 | 正式所选版本与原版等价，耗时差异不作提速结论 |

数值状态MB为实际数组/张量及少量配置的字节数除以10^6，不等于进程峰值运行内存、模型下载体积或显存。当前灰关联约4.938 MB（Dig）和13.833 MB（Amazon），四组参数变化只增加少量状态。

Diginetica中B的Recall、MRR、NDCG高于本轮三个GNN，且平均响应更短；Amazon中灰关联平均响应约3.7—5.1 ms，GNN约1.1—1.4 ms，灰关联没有推理速度优势。Amazon C的MRR最高，但Recall与NDCG仍低于GC-SAN。轻量化结论应拆分为数值状态、计算响应和推荐质量，分别报告。

## 11. 研究结论与适用范围

1. A在两个数据集均有改善，表明固定ρ=0.5并非当前任务下的最佳已测设置。
2. B在两数据集均提高三项总体质量，Dig收益最明显；β选择反映覆盖率与前部排名的取舍，不能固定以更强压缩代表更好性能。
3. C在两个数据集选出相反权重方向；Dig同时出现Recall下降与MRR上升，说明选参指标会影响最终结论。
4. D的正向惩罚在验证集持续降低质量，最终退回原版，是本轮明确的失败方案。
5. 分组结果揭示总体提升的来源及代价：Dig B改善重复与新目标命中，Amazon的灰关联改动主要改善训练已见目标。当前结果没有证明冷启动提升或跨划分稳定性。
6. B可作为重点讨论方案，A、C、D构成不同实现环节的独立对照。A/B在共同差异端点、统一ρ、同权聚合及β<1/ρ的条件下存在正仿射排序关系，不能据四组标签宣称四种完全独立的数学机制。上述数学性质、预测结果和机制解释分别陈述；不声称方法首创、全灰关联公理成立或统计显著性。
