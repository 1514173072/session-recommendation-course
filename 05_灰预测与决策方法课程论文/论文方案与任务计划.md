# 论文方案与任务计划

## 1. 统一研究定位

课程：《灰预测与决策方法》。当前暂定题目：**《面向电商会话推荐的灰色关联模型改进与比较研究》**。

研究围绕同一推荐任务，分别改变原版灰关联的分辨系数、差异函数、转移指标权重和一对指标交互聚合，在Diginetica主要实验与Amazon-M2扩展实验上，对比原版及三个GNN的推荐质量、计算响应与数值状态。四组独立改动，不叠加。

B差异压缩是表现较突出的方案，置于四组比较中重点讨论；原“差异压缩＋轻量化”的单一题目作为历史定位保留，不再控制整篇结构。计算效率是实验分析的一部分。灰关联在Amazon响应更慢，因此不把“普遍更快”作为论文主论点。

目前暂无字数、模板或截止时间要求；教师后续通知优先。按中文课程研究论文推进，不移用原算法课的六人分组、展示时长与材料提交规定。

## 2. 研究问题

1. 原版GRA在两套既有会话推荐设置下，质量和计算成本如何？
2. 四个环节的单因素改动各自带来什么收益或损失，验证选出的参数是否一致？
3. A与B存在哪些条件化的数学关系，C与D的评分偏好如何变化？
4. 总体质量变化来自哪些目标分组，覆盖率与前部排名有哪些取舍？
5. 相比现有GNN配置，灰关联的优势与局限分别体现在哪些指标和数据设置中？

## 4. 统一实验设置与完成状态

| 项目 | Diginetica | Amazon-M2 ES |
|---|---|---|
| 验证/测试会话 | 20,000 / 20,000 | 8,886 / 8,970 |
| 目录商品 | 32,968 | 42,503 |
| GRA指标 | 转移、共现、重复、热度 | 转移、共现、文本、品牌、颜色、材质、价格、热度 |
| 归一化 | 每请求完整目录min-max | 既有0—1行为与属性构造，无额外逐请求min-max |
| 再访规则 | 允许推荐历史商品 | 过滤历史商品 |
| GNN | 原检查点 | 原属性融合检查点，复用静态目录缓存 |
| 参数(A,B,C,D) | (1,7,−1,0) | (1,2,2,0) |

每组5档，恢复参数共享原版，总计各17个验证配置。按验证MRR优先选参；完整测试每数据集8种方法。CPU4线程、batch=1、同300请求×3轮，共900次计时/方法。模型加载与静态目录预计算不计入请求耗时；静态目录张量计入数值状态。

231,760条测试预测、34项验证配置、14,400次计时已通过独立复算。原版GRA与原三个GNN的Top-10和历史结果一致。本轮未重训，不将重新推理写成重新训练复现。

Dig B的质量最高；Amazon GC-SAN的Recall与NDCG最高，C的MRR最高。D均选择0。完整数值只维护在[整合报告](四组灰关联两数据集测试整合报告.md)和权威CSV，不在计划中复制旧计时表。

## 5. 数学分析与结果解释口径

- A与B在共同端点、统一正ρ、同权聚合且β<1/ρ时，存在正仿射关系；本轮网格不同，不能将二者的实验差异直接解释为完全独立的数学机制。
- β=2的线性化以差异端点为条件。Amazon使用该参数完成全测试；Dig完整测试采用β=7，β=2只有本轮验证结果。
- C是固定转移权重，Dig降低、Amazon提高。Dig的Recall下降但MRR上升，要同时报告。
- D在0—1参数范围具有单调、归一化的聚合性质，实际非零惩罚无收益。数学合法性与预测有效性分别论证。
- Dig的会话内未浏览目标与Amazon的训练未见目标定义不同。Amazon训练未见组仅200条，不合并成统一“冷启动组”。
- 已有分组结果定位改善来源；公式解释与因果机制验证分别陈述，不把行为机制猜测写成实验事实。

## 8. 主张边界

已支持的是当前两套配置中的质量、响应和数值状态结果，以及所列数学条件下的代数性质。较小数值状态不等于进程峰值内存更低，也不自动等于响应更快。两套测试集均有历史查看记录，GNN沿用单种子与既有配置，研究定位为探索性课程比较。没有证据支持跨划分稳定、普遍优于深度学习、方法首创或统计显著性结论。
