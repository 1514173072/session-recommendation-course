## 已确认的研究内容

用户于 2026-10-29 提供以下要求，作为当前作业的内容依据：

> 选一种深度强化学习/机器学习/群智能优化算法开展研究，应用其解决一个具体工程问题，包括：工程问题描述、问题建模、算法设计思想与伪码描述、时间复杂度分析、设计对比实验并分析结果、讨论算法局限性以及失败案例等。

据此，工作围绕“一个具体工程问题 + 一种主算法 + 完整的分析与实验”组织。三类算法均在允许范围内，主算法确定后，对比实验可采用其他算法作为基线。

| 必需内容 | 后续应形成的可检查成果 |
|---|---|
| 工程问题描述 | 应用背景、实际任务、解决目标与输出用途 |
| 问题建模 | 输入、输出、变量与假设；优化任务明确目标和约束，预测任务明确预测对象与损失 |
| 算法设计思想与伪码 | 核心机制、关键步骤、输入输出和可对应实现的伪码 |
| 时间复杂度分析 | 定义问题规模符号，分析适用的训练、求解或推理成本 |
| 对比实验与结果分析 | 基线、统一的数据或环境条件、评价指标、实际结果与解释 |
| 局限性与失败案例 | 适用条件、具体失败场景及其原因，结合实际结果讨论 |

上述为内容要求。P10 中的课堂讨论组织安排继续单独保留；期末大作业的分组、截止时间和提交规范仍按具体通知确认。
