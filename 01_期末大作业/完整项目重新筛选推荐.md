## 1. 建筑能效评分：优先推荐

仓库：[WillKoehrsen/machine-learning-project-walkthrough](https://github.com/WillKoehrsen/machine-learning-project-walkthrough)。

建议题名：**基于梯度提升树的建筑能效评分预测与计算代价分析**。

建筑属性与已记录的能耗等信息 → 预处理与特征构造 → 梯度提升树估计 ENERGY STAR 评分 → 对照评价和误差解释。任务是评分估计，不应改称未来能耗预测或节能干预效果。

本轮核查的实际材料：
- data/Energy_and_Water_Data_Disclosure_for_Local_Law_84_2017__Data_for_Calendar_Year_2016_.csv：约8.28MB原始CSV；已读取真实表头。
- data/cleaned_data.csv 及 training/testing_features、labels：清洗和已划分数据；读取了测试特征与训练标签正文。
- Machine Learning Project Part 1.ipynb：清洗、探索、特征工程与初始基线。
- Part 2：线性回归、SVR、随机森林、梯度提升、KNN，随机搜索/网格搜索与MAE比较，含耗时和残差分析。
- Part 3：特征重要性、LIME、预测正确与严重错误的具体案例、总结。本轮读了正文，不只是目录。
- Building Data Report.pdf、hw_assignment.pdf、字段说明PDF在仓库中；本轮核对其存在，没有阅读这些PDF正文。
- images/包含模型比较、残差、局部解释与错误案例图。

为该用户推荐的理由：业务表格数据、清洗、回归、集成与解释经验可直接衔接；核心流程及分析材料都已给出。可以先以GBDT为主算法；若希望与同学XGBoost题目拉开方法差别，也可采用仓库已有随机森林模型，但需重组主线。

需明确处理：
- 旧sklearn.preprocessing.Imputer、GBDT的loss='lad'以及部分Pandas/Seaborn调用需现代化；目录中未见完整锁定环境。
- 初始模型选择多次使用同一test集合，特征探索和筛选在最终划分前进行。若做正式泛化评价，应在原始数据层重新冻结独立测试，全部选择放在训练/验证内。
- 输入包括Site EUI等评分相关信息，应定义为这些信息已知时的评分估计，避免夸大部署适用性。
- 仓库元数据未给出可识别license；本轮仅推荐学习与检查，后续若需分发修改代码需核对授权。

上述改变是复现和评价质量的整理，不需要重新寻找基础数据或从零搭建实验体系。

## 3. Attention Model + REINFORCE：配送路线优化

仓库：[wouterkool/attention-learn-to-route](https://github.com/wouterkool/attention-learn-to-route)。

建议题名：**基于注意力模型与 REINFORCE 的旅行商路线优化及计算代价分析**。先限于TSP20；CVRP是后续可选扩展，不在本轮自动扩题。

城市坐标 → 注意力编码/逐步选点 → 构造访问每个城市一次的回路 → 用路线长度作为优化信号训练策略 → 与启发式算法比较路线质量与耗时。

已核对：
- generate_data.py：TSP、VRP等实例生成，支持固定种子和实例规模；训练在线生成数据，因此无需额外申请真实数据。
- run.py、train.py、reinforce_baselines.py：训练与rollout等基线机制；本轮读取run.py，目录确认其余两项存在。
- pretrained/tsp_20、tsp_50、tsp_100等：权重及配置实际文件在目录中。本轮未读取二进制权重或加载验证。
- eval.py：贪心/采样等解码，保存路径、成本和计时。
- problems/tsp/tsp_baseline.py：最近邻、nearest/farthest/random insertion等；相关插入算法代码已读。Gurobi调用为延迟导入，可先选择不依赖外部求解器的基线。
- README给出生成、训练、评估和基线命令，含路径图、CVRP绘图Notebook及ICLR2019论文链接。论文链接是材料入口，本轮没有核对论文数值。

主要条件：
- 作者README说明不再积极维护；environment.yml仍残留cuda91，不能原样当现代环境配置使用。
- 默认每轮128万实例、100轮；课程训练必须按预算缩小，完整重训需要更多计算资源。预训练评估与自行训练需分开报告。
- 外部Concorde/LKH/Gurobi各有额外安装条件，选择最近邻/插入基线可缩小部署范围。
- 实例是随机几何图，结论先限于该分布上的路线优化，不直接推广为真实道路配送收益。

推荐理由：工程问题和算法机制清晰，数据可生成、模型可训练、预训练可评价、对照与计时已有入口，课程算法分析内容充足，方法学习门槛高于前两项。
