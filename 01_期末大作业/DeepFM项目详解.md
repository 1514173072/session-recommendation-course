# DeepFM 项目详解与课程作业切入点

日期：2026-10-29。状态：候选项目讲解；未确定选题、未安装依赖、未运行训练。

## 项目定位

拟采用 [shenweichen/DeepCTR-Torch](https://github.com/shenweichen/DeepCTR-Torch) 中的 DeepFM 模型。该仓库是点击率预测模型库，提供模型、特征接口、训练评估和示例；课程作业需据此组织正式数据、消融与对照、复杂度分析和失败案例。

DeepFM 将 FM 与深度网络联合训练，学习低阶与复杂的非线性特征交互；可参阅 [IJCAI 2017 原始论文摘要](https://ijcai.org/proceedings/2017/239)。本说明的实现细节主要依据本轮实际读取的仓库代码，不据论文结果预测本项目效果。

建议题名：**基于 DeepFM 的广告点击率预测与计算复杂度分析**。

## 工程任务与输入输出

广告展示前可用的特征 X → 模型输出点击概率 p → 可作为候选广告排序的一项输入。训练标签 y=1 表示点击，y=0 表示未点击；训练时才使用标签。

“设备类型 × 时段 × 广告类别”可作为理解交互的假设例子，不是 Criteo 匿名字段的真实语义，也不是实验发现。

Criteo Kaggle 数据的字段结构为 label、13 个整数特征 I1–I13、26 个类别特征 C1–C26，含缺失值，字段语义未公开。原始竞赛描述见 [Kaggle 数据说明](https://www.kaggle.com/c/criteo-display-ad-challenge/data)。仓库中的 criteo_sample.txt 经本轮读取计数只有 200 条数据，不适合正式模型比较。

数据说明还记录正负样本采取了不同抽样率。因此，模型输出首先是在所用抽样数据分布上的概率估计；未经抽样率修正或概率校准，不能直接认定为真实线上总体 CTR。离线 AUC 改善也不能直接折算线上点击或收入提升。

## 三个部分如何计算

实际源码：
[deepfm.py](https://github.com/shenweichen/DeepCTR-Torch/blob/master/deepctr_torch/models/deepfm.py)、
[inputs.py](https://github.com/shenweichen/DeepCTR-Torch/blob/master/deepctr_torch/inputs.py)、
[core.py](https://github.com/shenweichen/DeepCTR-Torch/blob/master/deepctr_torch/layers/core.py)。

### 类别嵌入

每个类别字段先把取值映射为整数 ID，再从可训练的嵌入表查出 k 维向量。ID 是索引，不表示类别大小关系。每个字段拥有自己的词表，未知类别需规定映射规则。

示例 k=4，26 个类别字段产生 26 个四维向量。数值特征按约定变换和缩放后单独输入。

### 线性项

给每个当前类别及数值特征一个权重，求和形成一阶得分。它对应可加的单特征贡献。

### FM 二阶交互

对类别嵌入向量 e_i、e_j 求内积，再对不同字段的组合求和：

\[
z_{\mathrm{FM}}=\sum_{i<j}\langle e_i,e_j\rangle.
\]

这个实现的 FM 分支输入是 sparse_embedding_list，即类别嵌入；13 个数值特征进入线性项和 DNN，不直接进入此 FM 二阶分支。不能照搬“全部 39 个字段都在 FM 中两两交互”的描述。

FM 用同一组类别向量参与不同组合，可减少为每个类别对单独估计参数的需求；极少出现的类别仍可能学得不充分。

### DNN 分支与合并

把同一组类别嵌入展开，和数值特征拼接后输入多层感知机。FM 和 DNN 共享类别嵌入参数；线性项使用独立的一阶权重。

按示例 26 个类别字段、k=4、13 个数值字段，DNN 输入维度为 26×4+13=117。DeepFM 类的默认隐藏层为 (256,128)，因此主要尺寸为：

- 类别嵌入：(B,26,4)；
- FM 输出：(B,1)；
- DNN：117 → 256 → 128 → 1；
- 线性项、FM 和 DNN 得分相加，再加入输出偏置并经过 sigmoid。

\[
\hat p=\sigma(b+z_{\mathrm{linear}}+z_{\mathrm{FM}}+z_{\mathrm{DNN}}).
\]

DNN 学习非线性组合；代码并不显式枚举和标注每一种三阶、四阶交互。三个分支通过同一预测损失一起更新。

## 训练目标与伪码

二分类交叉熵加参数正则化：

\[
\mathcal L =
-\frac1N\sum_{n=1}^N[y_n\log\hat p_n+(1-y_n)\log(1-\hat p_n)]
+\mathcal R(\theta).
\]

源码把不同参数组的正则强度分别配置。示例使用 Adagrad、batch_size=32，默认训练 10 个 epoch，可通过环境变量调整。示例为训练与验证输出指标，最终在测试集计算 AUC/LogLoss；示例没有显式配置保存最佳验证模型的回调。

正式作业可采用以下协议：

~~~text
输入：原始样本、字段定义、嵌入维度、网络层宽、训练配置
1. 固定样本选择规则，划分训练、验证与测试集
2. 仅在训练集拟合类别词表和数值变换，预留未知类别
3. 初始化共享嵌入表、线性权重和 DNN 参数
4. 对每个训练轮次：
      对每个训练批次：
          查表得到类别嵌入
          计算线性、FM、DNN 得分及点击概率
          计算交叉熵与正则，反向传播并更新参数
      使用验证集评估，按预定规则保留最佳模型
5. 恢复最佳模型，在测试集一次性汇总最终指标
输出：模型、预测、性能与计算代价记录
~~~

Criteo 原始记录具有时间顺序；若目标是预测后续展示，可设计按原始顺序留出的验证/测试。须确认实际下载版本保留该顺序。200 条演示文件不提供足够的时间验证依据。

## 适合课程的比较设计

固定数据划分、输入信息、评价集和训练预算规则，开展四个结构对照：

| 名称 | 线性项 | FM | DNN |
|---|---|---|---|
| LR | 有 | 无 | 无 |
| FM | 有 | 有 | 无 |
| 线性项 + DNN | 有 | 无 | 有 |
| DeepFM | 有 | 有 | 有 |

直接在 DeepFM 类中设置 use_fm=False 仍保留线性项，因此第三行应准确命名。设置 dnn_hidden_units=() 可关闭 DNN。若要求纯 DNN 对照，需要单独去除线性项，不能仅关闭 FM 后把结果写成纯 DNN。

需要注意：即使通过开关关闭分支，基类也可能仍创建嵌入表并注册正则。准确比较参数量时要区分已分配参数、实际参与前向的参数和参与优化的参数，运行代价按实际调用统计。对严格性能比较可另写最小基线；这仍处于建议阶段。

建议主实验先使用有明确抽样规则的 10 万条规模子集，确认样本组成与资源后决定是否扩大。该规模是课程工作量建议，不是统计充分性保证或已测运行配置。

实验按优先级组织：
1. 四种结构，固定评价协议与模型选择预算，运行多个随机种子。
2. 一个结构参数系列，如 k∈{4,8,16}，观察精度与代价变化。
3. 样本量、训练频次或未见类别分组，选其中一项作补充。
4. 检查误差最大的样本与系统性失败分组。

评价：
- AUC：点击与未点击样本的排序区分能力；
- LogLoss：真实标签对应概率的损失，错误且过度自信的预测惩罚较大；
- 计算代价：训练耗时、固定批量推理耗时/吞吐、模型参数、内存或显存；
- 辅助：概率校准、类别频次分组表现。正负不平衡时不以准确率作为唯一结论。

DeepFM 是否胜过 FM、增加维度是否改善、哪些场景失败，都须由实际实验确定。

## 时间复杂度为何值得分析

依据 [FM 源码](https://github.com/shenweichen/DeepCTR-Torch/blob/master/deepctr_torch/layers/interaction.py)，对 F 个类别字段、每个 k 维向量：

\[
\sum_{i<j}\langle e_i,e_j\rangle
=\frac12\sum_{t=1}^k\left[
(\sum_{i=1}^F e_{it})^2-\sum_{i=1}^F e_{it}^2
\right].
\]

逐对计算是 O(F²k)，使用上式为 O(Fk)。这是二阶交互模块的优化，不是整个 DeepFM 都只有 O(Fk)。

令 r 为数值字段数、D=Fk+r、隐藏层宽度为 h_1,...,h_L，包含最终输出层的乘法规模为

\[
W=D h_1+\sum_{\ell=2}^L h_{\ell-1}h_\ell+h_L.
\]

在固定架构、通常的稠密矩阵计算假设下，单样本前向的主要成本为

\[
C=O(Fk+r+W).
\]

每个类别字段的词表大小为 V_j，嵌入参数规模为 k∑V_j，因此大量类别可使参数表和优化器状态占据主要内存。

不能机械地把训练成本只写成 O(TNC)。本轮源码核查发现：
- create_embedding_matrix 使用 sparse=False；
- get_regularization_loss 每批扫描注册的整个参数表计算 L2；
- 示例采用 Adagrad。

令 P 为包含嵌入与线性表的参数总量、B 为批量、T 为轮数，则当前实现中可将主要训练成本写为以下估计，并说明参数组和优化器实现条件：

\[
O\left(T\left[N C+\lceil N/B\rceil P\right]\right).
\]

其中 C 此处表示单样本主要前向算术量 Fk+r+W，反向传播的同阶常数并入大 O；第二项反映逐批全表正则及稠密更新等代价。若改为稀疏更新或批次正则，复杂度口径会改变。正式报告应按冻结代码继续核验并配合实测，不把理论大 O 当作硬件耗时。

## 局限与可检查失败

- 罕见/未见类别：嵌入样本不足或统一 OOV 丢失差异；可按训练频次及未见状态分组。
- 过拟合：样本小而词表、嵌入或网络大，训练改善但验证恶化；可记录曲线与正则敏感性。
- 分布变化：后续展示中的组合与训练不同；可按合理顺序划分检查，前提是数据版本保留顺序。
- 匿名特征：可研究模型误差与类别频次，业务语义解释受限。
- 离线到线上：历史展示、抽样方式与线上排序环境不同；本项目首先评价离线预测，不直接据此给出线上收益结论。

以上是建议检验的条件与场景，尚未得到本课程实验结果。
