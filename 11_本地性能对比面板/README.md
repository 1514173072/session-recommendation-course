# 本地推荐性能对比面板

交付文件：`D:\Projects\算法分析与理论课程\08扩展对比\推荐性能与耗时对比.html`。单文件嵌入数据、样式和脚本，可在本地浏览器打开，不依赖网络或模型服务。

勾选算法后，Recall@10、MRR@10、NDCG@10、平均耗时与P95同时展示。可切换原30条、固定1000条和完整20000条，点击表头排序。没有当前范围结果的方法会置灰，缺少同口径P95显示“—”。

按用户最新要求：移除MLP、OpenCode Go模型、固定教师分组策略和单Token同步过程方案；加入仅修改差异d的β=7改进灰关联。保留原始及改进灰关联、三种GNN、原版Qwen有/无强模型关联分析、离线Qwen，共8项。“教师指导”统一显示为“强模型关联分析”，内部实验ID保持原样。

原版在线Qwen仍只有30条结果；离线Qwen为有教师版本，已完成20000条。改进灰关联的30/1000条质量来自保存预测的对应子集，耗时沿用历史900次实测；页面已注明计时范围。

`build.py`只读取既有实验记录并生成HTML，不运行模型实验。`data_manifest.json`保存数据源指纹；`dist/index.html`为同一份页面的本地预览副本。
